# LPC 素材來源與授權

`lpc-walk.png` 是由以下兩張 LPC spritesheet 的「走路」列合成的：上排朝下（正面）、下排朝右（側面），各 9 格，每格 64×64。

| 部件 | 作者 | 授權 |
|---|---|---|
| 身體 `body/bodies/male`（light） | bluecarrot16, Benjamin K. Smith (BenCreating), Evert, Eliza Wyatt (ElizaWy), TheraHedwig, MuffinElZangano, Durrani, Johannes Sjölund (wulax), Stephen Challener (Redshrike) | CC-BY-SA 3.0, GPL 3.0 |
| 頭 `head/heads/human/male`（light） | bluecarrot16, Benjamin K. Smith (BenCreating), Stephen Challener (Redshrike) | OGA-BY 3.0, CC-BY-SA 3.0, GPL 3.0 |

- 原始發布：OpenGameArt — [Liberated Pixel Cup (LPC) Base Assets](https://opengameart.org/content/liberated-pixel-cup-lpc-base-assets-sprites-map-tiles)、[LPC Character Bases](https://opengameart.org/content/lpc-character-bases)
- 取得來源：[Universal LPC Spritesheet Character Generator](https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator)（`spritesheets/` 與 `CREDITS.csv`）。本工作環境無法直接連線 OpenGameArt，所以改從這個 GitHub 鏡像下載，內容與授權資訊都取自它的 `CREDITS.csv`。
- 依 CC-BY-SA 3.0，本合成圖以相同授權（CC-BY-SA 3.0）釋出，並保留上列作者署名。
